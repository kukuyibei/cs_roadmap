# C 语言踩坑与错题本

## 1. 编译错误
- **错误提示**：`error: expected ';' before '}' token`
  - **原因**：上一行语句结尾漏了分号。
  - **解决**：找到报错行号的上一行，补上分号。

- **错误提示**：`warning: format '%d' expects argument of type 'int', but argument 2 has type 'double'`
  - **原因**：`printf` 格式符和变量类型不匹配（比如用 `%d` 打印了 `float`）。
  - **解决**：换用正确的格式符，如 `%f`。

## 2. 逻辑陷阱（运行时错误）
- **坑点 1**：`if (a = 5)` 
  - **现象**：判断永远为真。
  - **原因**：把比较 `==` 写成了赋值 `=`。
  - **防范**：建议写成 `if (5 == a)`，如果不小心写成 `=` 会直接编译报错。

- **坑点 2**：`80 <= score < 90`
  - **现象**：无论 score 是多少都成立。
  - **原因**：C 语言不支持连续比较，会先算 `80 <= score`（结果为0或1），再用这个结果去和 90 比。
  - **防范**：写成 `score >= 80 && score < 90`。

- **坑点 3**：`unsigned int a = 0; a = a - 1;`
  - **现象**：`a` 变成了 4294967295。
  - **原因**：无符号整数溢出回绕。
  - **防范**：明确数据类型范围，避免混用 signed 和 unsigned 做减法/比较。

## 3. 运算与优先级坑
- **坑点**：`int a = 5 / 2;`
  - **现象**：`a` 等于 2，不是 2.5。
  - **原因**：两个整数相除，结果向零截断。
  - **解决**：写 `5.0 / 2` 或 `(double)5 / 2`。

- **坑点**：`SQUARE(2+3)` （如果宏定义是 `#define SQUARE(x) x * x`）
  - **现象**：结果是 11，不是 25。
  - **原因**：宏只是文本替换，变成了 `2+3 * 2+3`。
  - **解决**：宏参数必须加括号：`#define SQUARE(x) ((x) * (x))`。
