# C 语言边界测试报告

## 1. 整数溢出
- 现象：INT_MAX + 1 变成 -2147483648
- 原因：32 位补码，最高位溢出回绕
- 结论：涉及大数运算要用 long long，或做溢出检查

## 2. unsigned 回绕
- 现象：0u - 1 输出 4294967295
- 原因：无符号类型回绕到最大值
- 结论：循环用 size_t 从 0 开始递减会变成死循环

## 3. signed/unsigned 比较
- 现象：-1 < 1u 不成立
- 原因：signed 与 unsigned 混合运算时，signed 被转为 unsigned
- 结论：不要混用 signed 和 unsigned 做比较

## 4. 截断
- 现象：(char)300 = 44
- 原因：char最大位为256将int转为char时被截断
- 结论：在强制数据类型转换时，应注意数值是否过大

## 5. 负数取模
- 现象：-7 % 3 = -1（C99 起规定向零取整）
- 结论：如果要数学意义的模（结果非负），需要手写：
  ((a % b) + b) % b

## 6. 整除截断
- 现象：5/2=2 (double)5/2 = 2.500000 5.0/2 = 2.500000 -5/2 = -2
- 原因：当double除int时int会被类型转换成double 而当signed除unsigned时 结果会变成unsigned
- 结论：在计算除时应注意截断

## 7. 浮点精度
- 现象：0.1 + 0.2 != 0.3
- 原因：二进制无法精确表示 0.1 和 0.2
- 结论：浮点数不能用 == 比较，要用 fabs(a-b) < 1e-6

## 8. ++i vs i++
- 结论：++i先加后用 i++先用后加
