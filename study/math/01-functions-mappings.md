# 函数与映射

> 日期：2026-10-14
> 对应：第 1 周 · C 语言 · 数学部分

## 一、函数（映射）

**数学定义**：设 A、B 是两个集合，若对 A 中每一个元素，都有 B 中唯一的元素与之对应，则称这个对应为从 A 到 B 的函数（映射），记作：

    f: A → B

- A 叫**定义域**
- B 叫**陪域**
- 所有 f(a) 组成的集合叫**值域**，值域 ⊆ 陪域

### 与 C 语言函数的对比

| 概念 | 数学 | C 语言 |
| :--- | :--- | :--- |
| 定义域 | 集合 A | 参数类型 |
| 陪域 | 集合 B | 返回类型 |
| 规则 | f(x) 公式 | 函数体 |
| 唯一性 | 一个输入只对应一个输出 | 同一参数只返回一个值 |

**关键**：用 rand() 的函数每次返回不同值，不是数学意义的函数。数学函数必须是**确定**的。

## 二、单射（Injective）

**定义**：A 中不同元素映射到 B 中结果也不同。

    a₁ ≠ a₂ ⇒ f(a₁) ≠ f(a₂)

等价说法：f(a₁) = f(a₂) ⇒ a₁ = a₂

**例子**：
- f(x) = 2x（Z→Z）：单射
- f(x) = x²（Z→Z）：不是单射，f(2)=f(-2)=4
- f(x) = x²（N→Z）：是单射

**编程联想**：理想哈希函数应该是单射，但实际不是（所以有哈希冲突）。

## 三、满射（Surjective）

**定义**：B 中每个元素都至少被 A 中某个元素映射到。即**值域 = 陪域**。

    ∀b ∈ B, ∃a ∈ A, f(a) = b

**例子**：
- f(x) = 2x（Z→Z）：不是满射，奇数取不到
- f(x) = x + 1（Z→Z）：满射
- f(x) = eˣ（R→R）：不是满射，输出永远 > 0

## 四、双射（Bijective）

**同时是单射和满射**，也叫"一一对应"。

**意义**：A 和 B 之间存在双射，说明两者"大小相同"，可以一一配对。这是**计数**的基础。

**例子**：f(x) = x + 1（Z→Z）是双射。

## 五、与编程的联系

| 概念 | 编程场景 |
| :--- | :--- |
| 单射 | 哈希函数、去重、唯一键 |
| 满射 | 状态机输出、类型转换覆盖 |
| 双射 | 可逆加密、Base64 编码、XOR 加密 |

**举例**：
- MD5/SHA-256：理论非单射（输出空间有限），但实际找碰撞难
- UTF-8 编码：从 Unicode 码点到字节序列是单射
- XOR 加密：a XOR k XOR k = a，是双射
