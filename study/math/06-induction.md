# 数学归纳法 (Mathematical Induction)

> 日期：2026-11-07
> 对应：第 2 周 · C 语言 · 数学部分

## 一、什么是数学归纳法？
数学归纳法是一种用于证明**关于自然数的命题**对所有自然数（或某个起始点之后的所有整数）都成立的数学证明方法。

它的思想极其完美地对应了计算机科学中的**递归（Recursion）**。

## 二、证明的两个核心步骤

要证明命题 \(P(n)\) 对所有 \(n \ge n_0\) 成立，只需证明两步：

1. **基础步骤 (Base Case)**：
   证明当 \(n = n_0\)（通常是 \(n=1\) 或 \(n=0\)）时，命题 \(P(n_0)\) 成立。
   *（对应递归的终止条件）*

2. **归纳步骤 (Inductive Step)**：
   - **归纳假设**：假设当 \(n = k\)（\(k \ge n_0\)）时，命题 \(P(k)\) 成立。
   - **推导**：利用这个假设，证明当 \(n = k + 1\) 时，命题 \(P(k+1)\) 也成立。
   *（对应递归中的“信任子问题能算对，并在此基础上做本层计算”）*

如果这两步都成立，那么根据数学归纳法原理，命题对所有 \(n \ge n_0\) 都成立。

## 三、经典例题：证明求和公式

**命题**：前 \(n\) 个正整数的和等于 \(\frac{n(n+1)}{2}\)。
即证明：\(1 + 2 + 3 + \dots + n = \frac{n(n+1)}{2}\)

**证明过程**：

**步骤 1：基础步骤**
当 \(n = 1\) 时：
- 左边 = \(1\)
- 右边 = \(\frac{1 \times (1 + 1)}{2} = \frac{2}{2} = 1\)
左边 = 右边，所以当 \(n=1\) 时命题成立。

**步骤 2：归纳步骤**
- **假设**当 \(n = k\) 时命题成立，即：
  \(1 + 2 + \dots + k = \frac{k(k+1)}{2}\)
- **我们需要证明**当 \(n = k + 1\) 时，命题也成立，即证明：
  \(1 + 2 + \dots + k + (k+1) = \frac{(k+1)(k+2)}{2}\)

**推导过程**：
左边 = \((1 + 2 + \dots + k) + (k+1)\)
利用**归纳假设**替换括号里的部分：
= \(\frac{k(k+1)}{2} + (k+1)\)
提取公因式 \((k+1)\)：
= \((k+1) \left( \frac{k}{2} + 1 \right)\)
通分：
= \((k+1) \left( \frac{k + 2}{2} \right)\)
= \(\frac{(k+1)(k+2)}{2}\) = 右边。

因为基础步骤和归纳步骤都成立，所以原命题对所有正整数 \(n\) 均成立。

## 四、与 C 语言递归的深层联系

| 数学归纳法 | 递归函数 |
| :--- | :--- |
| **基础步骤** (证明 \(P(1)\) 成立) | **终止条件** (`if (n == 1) return 1;`) |
| **归纳假设** (假设 \(P(k)\) 成立) | **信任递归调用** (`factorial(k-1)`) |
| **归纳步骤** (用 \(P(k)\) 推导 \(P(k+1)\)) | **本层逻辑** (`return k * factorial(k-1);`) |

**程序员心法**：
写递归函数时，**不要试图在脑子里把多层调用展开**（这是人类大脑不擅长的）。你只需要像做数学归纳法一样：
1. 确定好终止条件（基础步骤）。
2. 假设你的函数对于规模更小的问题（\(n-1\)）是绝对正确的。
3. 写好当前这一层怎么利用上面的结果。
