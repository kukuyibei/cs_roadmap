3. 量词的否定（考试必考，编程必用）

“所有的天鹅都是白的” 的否定是什么？
错解：“所有的天鹅都不是白的”。
正解：“存在一只天鹅，它不是白的。”

公式（德摩根律的升级版）：

    ¬(∀xP(x))⇔∃x¬P(x)¬(∀xP(x))⇔∃x¬P(x) （不是所有都满足 = 存在不满足的）

    ¬(∃xP(x))⇔∀x¬P(x)¬(∃xP(x))⇔∀x¬P(x) （不存在满足的 = 所有都不满足）

编程体现：写 if 判断时，把“所有元素都 > 0”取反，应该是“存在一个元素 <= 0”，写成代码就是 for 循环里只要找到一个 <= 0 就 return false，而不是遍历所有元素去判断
