# 逻辑等价

> 日期：2026-10-25
> 对应：第 1 周 · C 语言 · 数学部分

## 一、什么是逻辑等价？
如果两个命题 P 和 Q 的**真值表完全相同**，即无论其中的变量取什么值，它们的真假结果始终一致，我们就称它们**逻辑等价**，记作：
**P ⇔ Q** 

逻辑等价在编程中的意义：它允许我们在不改变代码逻辑的前提下，**化简复杂的条件判断**，提高代码可读性和执行效率。

## 二、核心等价公式（与 C 语言对照）

### 1. 蕴含等价式（重点！）
**公式**：p → q ⇔ ¬p ∨ q
**解释**：“如果 p 那么 q” 等价于 “非 p 或者 q”。
**C 语言体现**：`if (p) { q }` 等价于 `if (!p || q) { ... }`。

### 2. 双条件等价式
**公式**：p ↔ q ⇔ (p ∧ q) ∨ (¬p ∧ ¬q)
**解释**：同真同假时，等价才成立。
**C 语言体现**：`(p && q) || (!p && !q)`，或者更简洁的 `p == q`。

### 3. 德摩根律（复习）
**公式**：
- ¬(p ∧ q) ⇔ ¬p ∨ ¬q
- ¬(p ∨ q) ⇔ ¬p ∧ ¬q
**C 语言体现**：
- `!(a && b)` 等价于 `!a || !b`
- `!(a || b)` 等价于 `!a && !b`

### 4. 分配律与吸收律
- **分配律**：p ∧ (q ∨ r) ⇔ (p ∧ q) ∨ (p ∧ r)
- **吸收律**：p ∨ (p ∧ q) ⇔ p
**解释**：在吸收律中，既然 p 已经为真，那么 `p || (p && q)` 的结果就只取决于 p，后面的 `(p && q)` 是多余的。
**C 语言体现**：`if (a == 1 || (a == 1 && b == 2))` 可直接化简为 `if (a == 1)`。
